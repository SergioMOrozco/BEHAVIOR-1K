This is where datasets will go by default. If you want to change that, you can use the OMNIGIBSON_DATA_PATH env variable.

## xlerobot / openarm_v2 USD models

The `xlerobot` and `openarm_v2` robot models are not yet part of the official
`omnigibson-robot-assets` download. Download their USD model files from this Google Drive folder:

https://drive.google.com/drive/u/1/folders/1ovyvuwKL5X8WAxmcpT_jyhZTyybiHsDj

and place them under `omnigibson-robot-assets/models/`, matching the existing per-robot layout
(e.g. `omnigibson-robot-assets/models/xlerobot/usd/`, `omnigibson-robot-assets/models/openarm_v2/usd/`).
